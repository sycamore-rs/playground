# Sycamore Playground

View the live website at <https://play.syacmore.dev>!

## Development

This project is structured to use [`cargo-sycamore`](https://github.com/sycamore-rs/cargo-sycamore)

```bash
cd client
# First install JavaScript dependencies
npm ci
# Run the dev server
cargo sycamore serve
```

That's it!
